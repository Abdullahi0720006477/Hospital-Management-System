# 🚀 Premium Admin Dashboard Features

## 🌓 Dark/Light Mode
- **Toggle**: Click the floating moon/sun icon in the bottom-left corner.
- **Persistence**: Your preference is saved instantly to your browser's local storage.
- **Integration**: Charts, tables, and the sidebar automatically adapt colors.

## 🤖 AI System Chatbot
- **Access**: Click the floating robot icon with the pulse effect in the bottom-right corner.
- **Features**:
  - **Live Updates**: Shows simulated real-time system alerts (e.g., "High CPU Load", "Security Warning").
  - **Interactive**: Type messages to get simulated system status reports.
  - **Status**: Always visible indicator showing "System AI Online".

## 🎨 Design 2026
- **Animations**: Header gradients flow continuously; cards float gently on hover.
- **Glassmorphism**: Sidebar and panels feature a frosted glass effect.
- **Typography**: "Outfit" font family for a clean, modern look.

2. Toggle the theme button to see the dark mode in action.
3. Open the chatbot and ask "status" to see the AI response.
